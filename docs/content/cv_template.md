# CV template specification

For the website's CV export (PDF). One page, single column, simple enough that software and people can both read it.

## Page

- **Size:** A4, portrait.
- **Margins:** about 1.5 cm to 2 cm on all sides.
- **Length:** one page. If the content does not fit, the CV studio should tell the student what to shorten, and should not shrink the text below the minimum sizes below.
- **Columns:** a single column. No tables, text boxes or images that hold text, so the PDF text can be selected and read by software.

## Fonts and sizes

- **Font:** one simple font, such as Arial, Calibri or Helvetica, used throughout.
- **Name:** 16 to 18 pt, bold.
- **Section headings:** 11 to 12 pt, bold, capital letters, with a thin line below.
- **Body text:** 10 to 11 pt. Never below 10 pt.
- **Line spacing:** about 1.1 to 1.2.
- **Colour:** black or dark grey for text. At most one dark accent colour for headings.

## Section order

1. **Contact:** full name, phone, email, city, and a LinkedIn link if the student has one. Leave out CNIC, date of birth, marital status and home address. A photo is not needed, so leave it out unless the employer asks.
2. **Education:** degree and major, university, years, and CGPA with the scale (for example 3.45/4.0). Latest first. Add relevant courses only if there is space.
3. **Experience:** internships, jobs and part-time work. For each: title, organisation, city or "remote", start and end month and year, and 2 to 4 bullets.
4. **Leadership and societies:** society roles, volunteering and events, in the same format as experience, with fewer bullets.
5. **Projects:** 1 to 3 academic or personal projects, each with one line on what it was and one on the result.
6. **Skills:** grouped in one or two lines (for example Software, Languages). List only skills the student really has.
7. **Achievements:** scholarships, honours lists, competitions and awards, one line each.

If a section is empty, leave it out. Do not leave blank headings.

## Bullets

- Start each bullet with an action verb in past tense (present tense only for current roles).
- One or two lines per bullet.
- Include a number where the student has one.
- Use a plain round bullet (•) and the same indent everywhere.

## Dates and consistency

- Write dates as "Jun 2025" (month, then year), with " - " between start and end, and "Present" for current roles.
- Write CGPA the same way everywhere.
- Spell organisations and tools the same way every time.

## Spacing

- 6 to 8 pt space before each section heading.
- 3 to 4 pt space between roles.
- No extra blank lines.

## File name

`Firstname_Lastname_CV.pdf`

## Checks before export

- [ ] Fits on one page
- [ ] Text in the PDF can be selected and copied
- [ ] No tables, columns or images holding text
- [ ] Dates, CGPA and headings written consistently
- [ ] No contact details of other people and no CNIC number
